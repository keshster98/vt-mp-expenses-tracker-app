# Expense Tracker App

This is a React Native project built with Expo.

The project is currently in development, so application features and screenshots are not included in this README yet.

---

## Setup Instructions

### 1. Clone the repository

```bash
git clone <repository-url>
cd <your-project-folder>
```

### 2. Install project dependencies

```bash
npm install
```

### 3. Start the Expo development server

```bash
npx expo start
```

---

## Running the App

Once the development server is running, you can open the project on different platforms.

---

### Android

#### Option 1: Physical device
- Install **Expo Go** from Google Play Store
- Ensure your phone and computer are on the same Wi-Fi network
- Scan the QR code shown in the terminal or browser

#### Option 2: Android Emulator
- Open your Android emulator (Android Studio)
- Press `a` in the Expo terminal

---

### iOS

#### Option 1: Physical device
- Install **Expo Go** from the App Store
- Scan the QR code using your Camera app or Expo Go

#### Option 2: iOS Simulator (Mac only)
- Open the iOS Simulator
- Press `i` in the Expo terminal

> Note: iOS Simulator only works on macOS

---

### Web

- Press `w` in the Expo terminal  
OR

```bash
npx expo start --web
```
